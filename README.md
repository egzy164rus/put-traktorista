# Путь тракториста — Берёзовка

Автономная версия игры для браузера и установки как PWA. Исходная сборка и все основные игровые ресурсы встроены в `index.html`; используются процедурные модели техники. При первом открытии необходимо интернет-соединение, чтобы браузер установил service worker и сохранил файлы; после этого игра может запускаться без сети в поддерживаемом браузере. Установка и автономность зависят от браузера и настроек устройства.

Карьера хранится локально в браузере/приложении, не в GitHub. Для переноса карьеры используйте «Карьера → Календарь и сохранение → Скачать сохранение», затем на новом адресе выберите и подтвердите восстановление JSON. Данные file://, GitHub Pages и установленного приложения могут быть раздельны в зависимости от браузера. При очистке данных сайта сохранения могут быть удалены, поэтому сохраняйте копию файла JSON.

Чтобы опубликовать: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. Обновление игры: изменить номер кэша в `sw.js`, иначе ранее сохранённые файлы могут остаться старыми. Заглавная иллюстрация является изображением, а не скриншотом игры.
